# Omnichannel AI Chatbot for E-commerce (n8n & Meta APIs)

This repository showcases an automated customer support and sales system built for online stores operating on Instagram, Facebook Messenger, and WhatsApp.

## Real-Life Use Case:
* **The Problem:** A clothing store was losing 40% of nighttime customer inquiries about sizes and prices.
* **The Solution:** Built an automated workflow using **n8n** connected to Meta Graph APIs and an AI Agent. The bot instantly answers product questions, collects customer shipping details, and notifies the store owner in real-time.

## Core Technologies:
* n8n Workflows & Webhooks
* Facebook Messenger & Instagram APIs
* AI Agents
